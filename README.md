# Campus Festival — チーム開発演習

学園祭の出店申請、会場予約、備品貸出、予算・経費、スタッフ配置を管理するブラウザアプリです。業務間のつながりを読み解き、Issueを通じてチームで改善します。

## 開く

1. ZIPの場合はフォルダー全体を展開します。
2. `index.html`をEdgeまたはChromeで開きます。インストール・サーバー起動・外部サービス接続は不要です。
3. 開発運用担当は教員から届くMarkdownで利用者報告を確認します。`reports.html`に取り込むと、届いた報告をまとめて検索し、整理メモを残せます。

インターネットなしでもアプリは動きます。GitHubを使ったIssue・PR作業にはネット接続とアカウントが必要です。ブラウザの保存設定によって保存を制限される場合は、通常のブラウザウィンドウで開き、JSONバックアップを利用してください。同じファイルを別フォルダーへ移すと保存データを引き継げない場合があります。

## 最初に試すこと

- ダッシュボードから全体像を確認する。
- 出店申請の下書きを作り、実行委員で承認して会場予約が作成されることを確かめる。
- 備品・貸出、経費、シフト、タスクをそれぞれ登録する。
- データ管理からJSONバックアップを書き出し、再読み込み後も内容が残ることを確かめる。

これは改善前の業務システムです。表示や計算に不具合が含まれます。データは架空です。本番の予算・個人情報を入力しないでください。

## ファイル構成

| ファイル                         | 役割                                     |
| -------------------------------- | ---------------------------------------- |
| index.html                       | 業務アプリの入口                         |
| assets/app.js                    | 画面、フォーム、保存、業務操作の接続     |
| assets/domain.js                 | 計算、検証、状態変更などの共通業務ルール |
| assets/seed.js                   | 架空の初期データ                         |
| assets/style.css                 | 画面の見た目                             |
| reports.html | 配布されたMarkdownを取り込む受信箱 |
| docs/                            | 業務とデータの説明                       |

ファイルを分割した通常のJavaScriptです。`file://`で動かすため、ES Modulesやfetchによるローカルファイル読込は使っていません。追加時もこの起動条件を守ってください。

## 保存と役割

業務データと受信箱メモは、このブラウザのlocalStorageに別々に保存します。別PCへの自動同期はありません。JSONを共有して同じ状態を再現してください。受信箱のメモは「整理メモを書き出す」で別途保存できます。

役割・団体の切替は業務操作の演習用です。本物のログイン認証やアクセス制御ではありません。複数人で同時に同一データを編集する仕組みもありません。チームで共有するのはGitリポジトリ上のコードです。
